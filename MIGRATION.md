# Перенос Flet → Dioxus

Актуализировано 13 ноября 2026 года. Локальные модели, инструменты агента и автоматический профиль добавлены; **перенос всех прежних возможностей ещё не завершён**.

Python/Flet/PyO3 и Flutter-расширение удалены из исходников и сборки. Старые исходники находятся в истории Git. Их удаление не означает, что каждая прежняя функция уже имеет реализацию на Rust.

## Проверки

- `dx build --desktop -p xopilot` создал бинарник и упаковал шрифт/иконку с установленными в системе GTK3/WebKitGTK/libxdo.
- Linux-приложение проверялось в настоящем WebKitGTK на отдельных временных базах, без чтения личной истории. Пройдены переходы, ввод, сохранение, отмена, перезапуск, ширины 1000 и 390 px. Проверен системный файловый chooser. [Результаты и обнаруженные ограничения](tests/UI_REVIEW.md).
- Rust-тесты проверяют шифрованную историю, сохранение неизвестных JSON-полей, проекты, шаблоны, Canvas, черновики, текстовые вложения, Markdown, пути, конфликты редактора и HTTP/SSE с отменой.
- Проверка рендера через Dioxus SSR дополнена `scripts/check-ui.cjs`: он проверяет настоящие события DOM и доступность кнопок в WebKit. Статический рендер не выявлял `inert="false"`, блокировавший открытое меню.
- JNI компилируется в Linux unit-test target; это не заменяет cross-build и тест на Android.
- Выполнен и Android cross-build с JDK 21, NDK 27.2.12479018, SDK 35. APK создан Gradle, манифест и состав native-библиотек проверены через aapt2/unzip.
- Настоящий локальный агент Gemma4-e2b прочитал, изменил и проверил файл в отдельной временной папке. Повторные одинаковые чтения были остановлены, итог сформирован из результатов инструментов.

Устаревшие инструкции и отчёты прежнего стека удалены. Сравнительные снимки сохранены как визуальный ориентир; актуальные проверки перечислены в `tests/TESTING.md`.

## Память и тестовый пакет

Текущий Android applicationId для тестовой сборки — `by.xopilot.test`, для основной — `by.xopilot.app`. Исторические отчёты предыдущих прогонов сохраняют фактические ID на момент проверки.

В окне «Память обо мне» добавлены категории, добавление, изменение и удаление записей. Выключение памяти исключает её из системного контекста. Инструмент агента save_memory сохраняет подтверждённые сведения в тот же список. Автоизвлечение распознаёт явные сообщения об имени, предпочтениях, работе и целях, пропускает вопросы и фразы с признаками секретов. При конфликте параллельных правок редактор сохраняет актуальную запись и сообщает об ошибке.

Сокращение длинного контекста локальной модели использует точные выдержки, без дополнительного вызова ИИ. Последний запрос сохраняется целиком. Один очень большой запрос или набор изображений может всё ещё превысить лимит модели.

## Дополнение от 13 ноября 2026 года

Автоматическая память преобразует явные утверждения в самостоятельные факты от третьего лица. При открытии профиля исправляются прежние автоматические цитаты. Ручные правки сохраняются, новое явно названное имя обновляет прежний автоматический факт.

В режиме агента доступны `search_web` через DuckDuckGo и `read_website` для чтения HTML-текста и ссылок. Для этих инструментов папка проекта не требуется. Выполнение JavaScript страниц и интерактивное управление браузером относятся к отдельной ещё переносимой функции.

Подключён анализ аудио и видео во вложениях. Звук декодируется в WAV mono 16 кГц, MP4/H.264 — в выбранные JPEG-кадры с временными отметками и аудиодорожку. Встроены Symphonia и OpenH264, дополнительные контейнеры могут использовать системные кодеки WebView. Исходники остаются в истории, подготовленный результат кешируется по хешу содержимого в каталоге данных приложения. Для текущего запроса ограничены длительность до 30 секунд, размер до 32 МиБ и число кадров до четырёх. API-провайдер должен поддерживать используемые мультимодальные части. Камера и демонстрация экрана остаются отдельными задачами; Live и озвучивание добавлены ниже.

На Linux проверены WAV, MP3, AAC-дорожка MP4, ролик с одним кадром, B-кадры и поворот дорожки. На настоящей Gemma E2B проверены чтение сайта, анализ кадров и распознавание речи из аудио. Android APK собирается с встроенными декодерами. Телефон при этой проверке отсутствовал в ADB, поэтому новый мультимодальный сценарий на устройстве ещё требует проверки.

## Диктовка

Кнопка микрофона записывает до 30 секунд mono PCM и передаёт WAV выбранной модели для транскрипции. Повторное нажатие завершает запись, во время распознавания — отменяет запрос. Текст добавляется к существующему черновику и сохраняется. При уходе приложения в фон захват звука прекращается. Linux захватывает PCM через нативный ALSA/CPAL, Android использует запись WebView с системным запросом разрешения микрофона. Режим Live и озвучивание добавлены следующим разделом.

Протокол записи проверяется через `./scripts/test.sh bridges` без обращения к микрофону. Для настоящей Gemma отдельно проверена транскрипция тестовой речи через сервис диктовки. Проверка физического микрофона и Android-диалога разрешения требует устройства и пользовательского разрешения на запись.


## Агентность, уточнения и голос — 13 ноября

Добавлены точный режим, пять исследователей и координатор с повторными поручениями каждому исследователю. Исследователи получают вложения текущего запроса и инструменты чтения/поиска; запись, команды и сохранение памяти доступны основному исполнителю по прежним правилам подтверждений. На Linux одна локальная модель выполняет исследования последовательно, API-запросы допускают параллельность. Все операции исследователей и публичные планы видны в чате. Выключенный агент не запускает команду из ранее сохранённых настроек.

Четыре уровня размышления задают 1–4 дополнительных прохода модели. Это отдельная работа с кратким планом и проверкой, не управление внутренним thinking budget SDK. Уточнение действующей задачи сохраняется перед применением и проверяется до выдачи финального ответа; новые инструменты старого шага не запускаются при ожидающем уточнении. Уже запущенное действие завершается. Неиспользованные уточнения возвращаются в черновик при завершении задачи. Порядок сброса старого потока и новых фрагментов сохраняется общей шиной событий.

Live чередует микрофон, ASR, обычный цикл чата и локальное озвучивание. Начало записи явно включается пользователем; уход в фон и остановка закрывают захват. После ошибки следующая стадия не запускается. Для локальной диктовки нужен аудиовариант Gemma E2B/E4B/12B Unified. У API должна быть поддержка input_audio. Голос и ИИ могут иметь разную скорость, поэтому Live работает по репликам, без записи собственного голоса во время воспроизведения.

На Linux базовая речь идёт через нативный eSpeak NG из проверяемого архива, без Python. Piper Руслан загружается отдельно с явным указанием CC BY-NC-SA 4.0. Отдельная загрузка голоса продолжается при сворачивании окна; полное завершение процесса Linux её не сохраняет как системную задачу. Android использует установленный русский голос TTS без сетевого требования, Windows — локальный голос WebView2. Отсутствие русского голоса возвращает ошибку, облачная замена не включается автоматически. RVC остаётся открытой задачей.

На подготовленной фразе проверены синтез Piper и распознавание настоящей Gemma E2B: основная часть фразы распознана, первое слово отличается. Базовый eSpeak синтезирует PCM, но его механическую речь Gemma в этом тесте распознала неточно. Физический микрофон автоматически не включался. Windows, акустическое качество динамиков и длительная беседа через реальные микрофоны требуют отдельных испытаний.
