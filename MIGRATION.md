# Перенос Flet → Dioxus

Дата: 10 ноября 2026 года. Это рабочая основа Rust-приложения, **не завершённый перенос всех возможностей**.

Python/Flet/PyO3 и Flutter-расширение удалены из исходников и сборки. Старые исходники находятся в истории Git. Их удаление не означает, что каждая прежняя функция уже имеет реализацию на Rust.

| Область | Состояние |
|---|---|
| Workspace, запуск, упаковка ресурсов | Cargo, Dioxus 0.7.10, Linux Desktop / Android Mobile features |
| Архитектура и стиль | Сохранены App/app, App/services, App/settings, assets, Services; русские заголовки, build_* |
| История SQLCipher | Сохранены схема, ключи и путь; проверены повторное открытие, неверный ключ, цитаты, вложения, время ответа |
| Чаты | История, поиск названий/сообщений с состоянием «ничего не найдено», совместимые закладки, переименование, правка, удаление, черновики, Markdown-экспорт |
| API | SSE и JSON-ответ, частичные UTF-8/CRLF, отмена, таймауты, проверка URL, прямые запросы провайдеру |
| Локальная модель | Только подключение к отдельно запущенному совместимому серверу. Загрузка .litertlm и управление моделью не перенесены |
| Вложения | Текст/код, растровые изображения с ограничениями декодирования, PDF, DOCX. Видео, XLSX, генерация офисных файлов не перенесены |

| Профиль | Имя, личные инструкции, сохранение неизвестных полей и прежней памяти. Редактор категорий памяти, автоизвлечение, аватар и восстановление конфликтов не перенесены |
| Шаблоны | Добавление, редактирование, удаление и вставка без отправки; защита несохранённой формы |

| Облачный аккаунт / E2EE sync / хранилище / тарифы | Не перенесены. Данные и настройки сохраняются; сеть синхронизации не запускается |
| Удалённые компьютеры / задания / браузер / MCP | Не перенесены |
| Обновления, диагностика и поддержка | Автообновление и подготовка диагностических вложений не перенесены |

## Проверки

- `dx build --desktop -p xopilot` создал бинарник и упаковал шрифт/иконку с установленными в системе GTK3/WebKitGTK/libxdo.
- Linux-приложение проверялось в настоящем WebKitGTK на отдельных временных базах, без чтения личной истории. Пройдены переходы, ввод, сохранение, отмена, перезапуск, ширины 1000 и 390 px. Проверен системный файловый chooser. [Результаты и обнаруженные ограничения](tests/UI_REVIEW.md).
- Rust-тесты проверяют шифрованную историю, сохранение неизвестных JSON-полей, проекты, шаблоны, Canvas, черновики, текстовые вложения, Markdown, пути, конфликты редактора и HTTP/SSE с отменой.
- Проверка рендера через Dioxus SSR дополнена `scripts/check-ui.cjs`: он проверяет настоящие события DOM и доступность кнопок в WebKit. Статический рендер не выявлял `inert="false"`, блокировавший открытое меню.
- JNI компилируется в Linux unit-test target; это не заменяет cross-build и тест на Android.

Старые отчёты в `tests/*.md` и изображения `previews/*.png` относятся к Flet, кроме файлов с префиксом `dioxus-`. Они не служат свидетельством работоспособности новой реализации.

## Следующие обязательные этапы до замены выпущенного приложения

1. Нативный LiteRT runtime, каталог/скачивание/выбор моделей и управление памятью.
2. Совместимые с прежними данными приватные чаты, аккаунт, облачное хранилище и E2EE sync.
3. Агент, подтверждения инструментов и удалённые задания.
4. Нативные аудио/голос/камера/экран для Linux и Android.
5. Остальные возможности редакторов, библиотеки, профиля, экспорта и обновлений.
6. Полный Android build, подпись прежним ключом и тест обновления существующей установки.
