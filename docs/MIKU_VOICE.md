# Локальный тембр Miku

Обновление от 3 октября 2026. Профиль Miku теперь использует отдельную обученную
RVC v2 модель голоса. Русский и английский Piper задают произношение текста,
ContentVec извлекает содержание речи, RMVPE — высоту, RVC синтезирует тембр Miku
в 48 кГц. Изменение частоты проигрывания Irina для имитации Miku убрано.
COVE/Ruslan и Maple сохранены.

Это модель сообщества, а не официальный голосовой банк Crypton. Точное совпадение
с конкретной песней или настройкой Vocaloid не заявляется. Карточка модели указывает
английский и японский языки; русский здесь обеспечивается исходной речью Piper.
Уровень сходства тембра оценивается прослушиванием, а не результатом распознавания.

## Установка и использование

Выберите «Настройки → Модели → Miku → Скачать», затем Miku в «Голос Live».
Выбор применяется со следующего ответа и сохраняется в локальной БД. Старые файлы
Irina/Amy без RVC больше не считаются полной установкой Miku. При ошибке голос
не заменяется другим диктором.

Из исходного проекта:

```sh
./python/linux/bin/python -m pip install -r App/requirements.txt
./python/linux/bin/python scripts/install_russian_voice.py --voice miku
```

Первый установщик скачивает закреплённые ресурсы с SHA-256, создаёт отдельную среду
с CPU PyTorch и экспортирует модель в ONNX. Он загружает checkpoint с
`weights_only=True`, проверяет все веса строго и сравнивает звук PyTorch/ONNX
на трёх длинах входа. Неполный экспорт не заменяет рабочую модель.
PyTorch используется только при подготовке, при озвучке он не импортируется.

Веса находятся в каталоге пользовательских моделей `tts/miku-rvc`, включая
`contentvec.onnx`, `rmvpe.onnx`, `miku.onnx`, `miku.json`, исходный checkpoint.
Около 980 МБ занимает установленный профиль с двумя Piper-моделями; среда экспорта
требует дополнительного места. `XOPILOT_MODELS_DIR` позволяет выбрать другой каталог.
Подготовленную папку моделей можно перенести целиком на другой компьютер, без повторного
экспорта. На Windows CLI запускается обычным Python. Если встроенный Python пакета
не умеет создавать venv, интерфейс сообщает об этом и предлагает CLI-подготовку.
Журналы лежат в пользовательских `runtime/miku-install.log` и `tts/miku-rvc/export.log`.

Синтез полностью локальный, использует ONNX Runtime CPU. В памяти один общий
конвертер для русского и английского; при смене профиля он освобождается.
Загрузка моделей и проверка их целостности проходят один раз на разговор.
«Перебить» передаёт отмену в Piper/RVC и закрывает поток звука; текущий нативный
оператор ONNX может закончиться перед обработкой отмены.

## Результаты проверки на Linux

- Все три скачанных ресурса совпали с закреплёнными SHA-256.
- Полная модель загрузила все 457 inference-тензоров с `strict=True`.
- При экспорте сохранены все обученные слои. Gaussian excitation noise передаётся
  входным тензором, чтобы сравнение не зависело от разных генераторов случайных чисел.
- Сравнение ONNX/PyTorch для 37/83/140 кадров: средняя абсолютная ошибка
  `4.40e-6 / 4.07e-5 / 1.12e-5`, максимальная `6.36e-5 / 1.12e-3 / 6.59e-4`.
- NumPy preprocessing RMVPE сравнён с librosa HTK/Slaney и `torch.stft`:
  ошибка mel-матрицы 0, максимальная ошибка log-mel `1.43e-6`.
- Реально синтезированы [русская](audio/miku-ru.wav) и [английская](audio/miku-en.wav)
  фразы. Локальная Gemma распознала все исходные слова русской фразы. В английской
  основной текст распознан правильно, но имя Miku в разных синтезах распознавалось
  как Miku/Nico/Mito. Для английского произношения имени исправлен краткий /ɪ/
  на /iː/ только в TTS; текст чата не меняется. Точность передачи собственных имён
  остаётся ограничением; эти проверки не подтверждают качество всей возможной речи.
- Для первых образцов 4.7/4.18 секунды звука синтезировались за 8.23/4.99 секунды
  соответственно; первый замер включает загрузку моделей. На другой машине
  задержка и потребление памяти будут отличаться; этот голос тяжелее Piper.
- Реальная отмена длинной конвертации завершилась через 1.08 секунды от начала
  вызова (сигнал выставлен через 0.15 секунды). Следующая конвертация того же
  экземпляра вернула корректное аудио 48 кГц; блокировка освобождена.
- Повторный экспорт через общий установщик в отдельную папку прошёл; подготовка
  стандартной среды экспорта тоже завершилась. Большие веса не добавлены в Git.
- Экспорт из пакета, содержащего только `.pyc` без исходных `.py`, тоже прошёл.
  TorchScript helpers хранят исходник в CompilationUnit, поэтому Flet compilation
  не мешает этому шагу. Встроенный launcher не запускается как Python для создания venv;
  без готовой среды предлагается CLI-подготовка через Python 3.14.
- 160 Python-тестов прошли, Rust check --offline прошёл, Linux-пакет пересобран.
- Реальный SpeechOutput проиграл Miku через sounddevice и завершился без ошибки.
  Упакованные модули отдельно проверены с зависимостями пакета; синтез идёт через
  ONNX Runtime и не импортирует PyTorch.

Windows-инференс, точное субъективное сходство и весь пользовательский проход
кнопок Live после этого изменения ещё не подтверждены.

## Источники и атрибуция

- [HidekoHaruna/RVC_V2_Hatsune_Miku](https://huggingface.co/HidekoHaruna/RVC_V2_Hatsune_Miku),
  revision `0a5ccf3ba0040aecc959a97bad2997e8a0482964`, checkpoint `MikuAI_e210_s6300.pth`.
  Автор описывает обучение на разных настройках Miku. Карточка не объявляет
  открытую лицензию весов и относит авторские права к Crypton Future Media;
  кодовая лицензия RVC не выдаётся за лицензию весов.
- [TigreGotico/voiceclonnx-rvc](https://huggingface.co/TigreGotico/voiceclonnx-rvc),
  revision `cbfbabdabe6a1414292bade8f857fb6074abf130`: FP32 ContentVec и RMVPE ONNX.
  INT8-варианты не используются.
- [SUC-DriverOld/rvc.onnx](https://github.com/SUC-DriverOld/rvc.onnx): полная архитектура
  и динамическая attention для ONNX, MIT, Copyright 2026 Sucial. Закреплённая revision
  и список изменений находятся в `App/services/_rvc_export/PROVENANCE.md`, лицензия рядом.
- [RVC-Project](https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI):
  RMVPE preprocessing и RVC, MIT. Исходная лицензия сохранена как `LICENSE.rvc`.
- Источники и лицензии базовых дикторских моделей: [каталог Piper](../App/data/models/tts/README.md).
