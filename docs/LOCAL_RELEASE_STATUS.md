# Xopilot: готовность локальной версии

Дата: 3 октября 2026. Целевые платформы — Linux и Windows. Облако, аккаунты и синхронизация отложены на следующий этап по решению пользователя.

Статус: Linux-пакет собран и запущен; основные пользовательские сценарии проверены в том же интерфейсе через локальный браузер. Полный релиз на обеих платформах ещё не подтверждён.

## Реализовано

- Сохраняемые чаты и сообщения, поиск и переименование чатов, редактирование текста и вложений, подтверждение удаления/очистки.
- Рабочие пространства с общими инструкциями, материалами, принадлежностью чатов и переносом между пространствами. Создание пространства сохраняет все параметры одной записью.
- Независимые от оригинала копии вложений в каталоге пользователя.
- Сохраняемые черновики, отмена редактирования, остановка и повтор генерации без дублирования вопроса; повтор использует исправленный текст вопроса.
- Реальные ответы LiteRT-LM. Ошибки модели и хранения отображаются; фиктивных ответов нет. При ошибке сохранения ответа доступно повторное сохранение без новой генерации.
- Live в отдельном окне: микрофон, выбор звуковых устройств и камеры, камера/экран с предпросмотром, текстовые вопросы при выключенном микрофоне, прерывание ответа, завершение и освобождение устройств.
- Диктовка в черновик. Голосовые контроллеры восстанавливаются после переподключения веб-страницы.
- Сохранён прежний стиль; компоновка адаптируется к узкому окну. Действия сообщений доступны постоянно. Тема применяется к чату, диалогам и новым разделам настроек.
- Локальный профиль, реальные счётчики, выбор моделей и голосов COVE/Miku/Maple, загрузчики с проверкой SHA-256, проверка опубликованных обновлений.
- Экспорт Markdown с предпросмотром, копированием и выбором файла сохранения.
- Список чатов прямо в раскрытом меню: поиск, текущий выбор, число сообщений и закрытые защищённые чаты.
- Защищённые анонимные чаты с отдельным паролем, шифрованием сообщений/Canvas/вложений и временная версия; изоляция от профиля, проектов и внешнего API. [Поведение и границы защиты](PRIVATE_CHATS.md).
- SQLCipher: транзакции сообщений и вложений, миграции, редактирование вложений одной транзакцией. Выбор существующего ключа сохраняется при изменении доступности keyring; при отсутствии ключа старой базы новый не создаётся.
- Модели и голоса устанавливаются в доступный для записи каталог пользователя. Прежние веса доступны для чтения при запуске из проекта.
- Нативная сборка размещает расширение атомарной заменой; GitHub CI собирает БД и запускает проверки перед упаковкой.

## Дополнение интерфейса и функций 3 октября

- Скруглённые поля с обводкой и такие же плавающие списки. Кнопки строки ввода и заголовка используют градиент меню; рамки чата, меню и строки ввода белые.
- Семь тем: Аква светлая/тёмная, Полночь, Океан, Лес, Лаванда, Закат.
- История показывает чаты, предпросмотр сообщений и поиск по содержимому. Название нового и прежнего безымянного чата выводится из первого вопроса; ручное название сохраняется.
- Имя профиля меняется карандашом справа; центрированные показатели включают размер DB/WAL/SHM.
- Проекты имеют 12 выбираемых иконок, инструкции, список чатов и библиотеку. Библиотека импортирует папку, копирует материалы, позволяет создавать/редактировать заметки, просматривать файлы и отключать их использование ИИ.
- Canvas сохраняет текст, код и свободное рисование. Поддерживает несколько документов, отмену последней линии, экспорт текста/PNG и прикрепление в чат.
- Агентность: низкий/средний/высокий/автоматический уровни. Реальная последовательность локальных инструментов поиска/чтения библиотеки и чтения/создания Canvas; прогресс, журнал и отмена. «Авто» расширяет число попыток с 3 до 7 и 15, если задача продолжается. Выполнение команд ОС и управление произвольными программами не реализованы.
- Каталог чата: Zephyr Micro (в разработке), Gemma4-e2b, Gemma4-e4b, API. Для обеих Gemma предусмотрен загрузчик с SHA-256. Источник E4B: [LiteRT Community](https://huggingface.co/litert-community/gemma-4-E4B-it-litert-lm), CPU-файл 3 659 530 240 байт, SHA-256 `0b2a8980ce155fd97673d8e820b4d29d9c7d99b8fa6806f425d969b145bd52e0`, проверен по метаданным источника 3 октября.
- API поддерживает совместимый Chat Completions endpoint, настройки URL/модели/ключа, историю, текстовые материалы и изображения; отмена закрывает соединение. Ключ сохраняется в SQLCipher. Live остаётся локальным. Это подключение к модели пользователя, не облачный аккаунт Xopilot.

## Проверено

- Последний проход: 185 Python-тестов с релизным нативным модулем, 4 Rust-теста и Rust check --offline прошли. [Новый чистый профиль и реальный проход интерфейса](CLEAN_USER_CHECKS.md).
- Miku использует отдельную обученную локальную модель тембра, а не изменение частоты воспроизведения Irina. Проверены синтез ru/en, прерывание, строгий экспорт и целостность моделей; [образцы, ограничения и протокол](MIKU_VOICE.md).
- 4 Rust-теста выбора ключа прошли, cargo check прошёл.
- Настоящая временная SQLCipher-БД: открытие, настройки, история, вложения, редактирование, удаление, очистка, откат, восстановление черновиков и параметров пространств.
- Реальные интерфейс, модель, камера, экран, запись и распознавание звука, озвучивание, общие материалы, перенос чата, профиль и тема: [подробный протокол](USER_CHECKS.md).
- Узкое окно 420×760: чат, настройки, экспорт и новый каталог моделей доступны.
- Реальный агент создал Canvas из библиотеки; режим «Авто» прочитал этот Canvas по названию и вернул правильные факты.
- Новый проход: защищённый/временный чаты, пароль, приватные вложения, черновик и Canvas; меню с поиском; проект/библиотека, профиль, тёмная тема, Live с файлами/камерой/экраном на GPU, Canvas кода/рисунка, агент и локальные экспорты. Окно 380×560 проверено.
- Реальные Markdown и PNG сохранены кнопкой «Локальная копия». Стандартная загрузка браузера остаётся неподтверждённой. PNG сохраняет пропорции рисунка.
- Через интерфейс пакета на новом каталоге моделей скачаны COVE ru/en, проверены SHA-256; проверено восстановление отсутствующей конфигурации и обновление отметки установки.
- compileall и git diff --check прошли.
- Релизный нативный модуль Linux собран и импортирован.
- flet build linux --yes --python-version 3.14 --no-rich-output завершился успешно. Итоговый пакет находится в build/linux/, запускаемый файл — build/linux/Xopilot.
- Нативный модуль в пакете совпадает с протестированным по SHA-256. В байткоде пакета присутствуют последние обработчики экспорта.
- Пакет запущен с новым профилем без весов: созданы база и каталог моделей. Затем запущен снова с той же базой, без ошибок открытия. Это проверка запуска, а не независимый просмотр всех нативных экранов.

Первая попытка упаковки остановилась из-за DNS при скачивании LiteRT-LM. После восстановления сети повторная сборка и последующие сборки с исправлениями завершились успешно.

## Ещё не подтверждено

- Нативный FilePicker в окнах обеих ОС. Ограничение управления локальной браузерной вкладкой устранено: новый Live и загрузка файлов проверены через настоящий браузерный интерфейс; это не отдельный проход нативного окна.

- Реальный внешний API с ключом пользователя: HTTP-путь, отмена и шифрованное хранение проверены тестами на локальном сервере; форма и ошибки проверены в браузере. Данные пользователя внешнему API при проверке не отправлялись.
- Загрузка и инференс Gemma4-e4b: установщик добавлен, метаданные источника проверены; веса E4B на этом компьютере не установлены. Zephyr Micro не доступна для инференса, помечена «в разработке».

- Сборка Windows и работа на настоящем Windows-устройстве, включая камеру, экран и звук.
- Чистая установка без Python и предварительно подготовленных весов: загрузка модели/голосов через интерфейс, сетевые ошибки, повторный запуск.
- Длинные диалоги у границы контекстного окна модели. История не обрезается произвольным лимитом приложения; возможности модели остаются ограниченными.
- Скачанный файл экспорта во встроенном браузере и выбор места сохранения в нативных окнах обеих ОС.
- Изменение доступности настоящего системного keyring при блокировке/перезапуске ОС. Автоматические проверки использовали тестовый поставщик ключа.
- Очистка неиспользуемых локальных копий материалов. История и метаданные зашифрованы; файлы материалов не зашифрованы SQLCipher.

Камера и экран отправляют текущий кадр для вопроса, а не непрерывное видео. Live — разговор с локальным ИИ; он работает по очереди, микрофон закрывается во время озвучивания. Одна запись диктовки ограничена 30 секундами.

## Запуск и проверка

    ./python/linux/bin/python scripts/build_native.py --offline
    ./python/linux/bin/python -m unittest discover -s tests -q
    cargo test --manifest-path Services/Cargo.toml --offline --lib
    ./python/linux/bin/flet build linux --yes --python-version 3.14
    ./build/linux/Xopilot

Локальный браузер:

    ./python/linux/bin/python scripts/run_web.py

Для отдельного профиля проверки добавьте --test-profile. Адрес — http://127.0.0.1:8559. Веб-клиент использует те же модели и устройства компьютера; при первом открытии возможна загрузка ресурсов Flutter из CDN.

На Windows используйте Python 3.14, python scripts/build_native.py, Python-тесты и flet build windows --python-version 3.14 --yes. Это инструкции для будущей проверки, а не подтверждение её успеха.
