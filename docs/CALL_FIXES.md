# Исправления Live — 3 октября 2026

## Изменения

- Окно Live оформлено в палитре приложения: градиентные кнопки микрофона, камеры, экрана и звука, читаемые состояния и текст последнего вопроса/ответа. Поле ввода и вложения вынесены из прокручиваемой части.
- Текстовый вопрос отправляется без камеры/экрана и может начать разговор. При выключенном микрофоне поток ввода не открывается. Второй ожидающий вопрос не заменяет первый.
- Файлы добавляются непосредственно в Live, передаются модели и сохраняются с сообщением в зашифрованной истории. После отправки удаляются из черновика; общие материалы пространства продолжают использоваться.
- Ошибка Piper/озвучивания сохраняет текст ответа и оставляет разговор открытым. Озвучивание можно отключить отдельно от микрофона. Неудачный захват изображения восстанавливает текст вопроса для повторной отправки.
- Удалена двойная регистрация FilePicker и Clipboard: Flet 1 регистрирует сервис при создании; дополнительное добавление в сервисы View создавало второй жизненный цикл для того же обработчика. Исправлено в чате, Live, пространстве, библиотеке, Canvas и сохранении копий.
- Рабочая папка, TMPDIR/TEMP/TMP, Flet storage и кеш LiteRT вынесены из App/.flet в каталог пользователя. Запись Python-байткода в исходники отключена. Это исключает записи во время инференса, которые `flet run -r` воспринимал как изменение кода.
- Устройство вычислений сохраняется в настройках: Авто/GPU/CPU. Авто учитывает свободную память NVIDIA и текущую загрузку, использует Vulkan GPU и переходит на CPU при ошибке инициализации. Принудительный GPU возвращает ошибку. Изменение применяется к следующему запросу без перезапуска приложения.

## Ограничение проверки интерфейса

Инструмент браузера заблокировал доступ к существующей вкладке `http://127.0.0.1:8559/`, указав недопустимый протокол. Обход блокировки не выполнялся. После этих исправлений не подтверждены визуальный результат через браузер, реальный выбор файла в системном диалоге и полный проход кнопок камеры/экрана/прерывания. Тесты проверяют контроллер и копирование выбранных файлов; они не проверяют системный диалог выбора. Нативный запуск в тестовом дисплее сообщил предупреждение OpenGL о размере кадра; traceback Python не было. Windows не проверена.

## Запуск

Перезапустить старый процесс и использовать исходники:

    ./python/linux/bin/flet run -r --ignore-dirs "data,__pycache__,.pytest_cache,.flet" App/App.py

Или обновлённый пакет:

    ./build/linux/Xopilot

Ускорение: Настройки → Персонализации → Устройство вычислений. В новом звонке после подготовки модели показано фактическое GPU/CPU. Причина перехода на CPU доступна в настройках устройства вычислений.
