# Проверка Xopilot через интерфейс

Дата: 2–3 октября 2026. Проверки выполнялись на Linux с настоящей локальной моделью Gemma 4 E2B, камерой, звуковыми устройствами и SQLCipher. Облако отложено по решению пользователя.

Последующий проход с новыми пустыми данными, защищёнными чатами, меню и исправленным Live описан в [CLEAN_USER_CHECKS.md](CLEAN_USER_CHECKS.md). Числа тестов и ограничения ниже относятся к указанным этапам.

Профиль проверки отделён от пользовательской истории. Запуск:

```sh
./python/linux/bin/python scripts/run_web.py --test-profile
```

Без `--test-profile` используется обычная база пользователя. Сервер слушает только `127.0.0.1:8559`. Веб-интерфейс использует тот же Python-код, устройства и модели этого компьютера. Он предназначен для локального использования. Первый запуск веб-клиента Flet может загружать ресурсы Flutter из CDN; автономность установленного настольного приложения от этого не зависит.

## Исправления, выявленные во время проверки

- Переподключение веб-страницы ранее оставляло голосовые контроллеры закрытыми навсегда. При подключении они восстанавливаются, запись и кадры при отключении освобождаются.
- Предпросмотр камеры теперь не может повторно открыть устройство после закрытия из-за опоздавшего рабочего потока.
- Если кадр недоступен, ответ на визуальный вопрос не генерируется без картинки. Отображается причина и предложение повторить вопрос.
- Устаревшие кадры не подставляются в новую реплику.
- VAD больше не заменяется заглушкой, которая считала любой звук речью.
- Действия сообщения доступны постоянно, включая управление с сенсорного экрана.
- Отмена из рабочего потока превращается в asyncio.CancelledError; её теперь обрабатывает обычный чат, сохраняя возможность повтора.
- После редактирования отменённого вопроса повтор использует новый текст. Кнопка повтора скрыта на время редактирования.
- Новые разделы настроек применяют текущую палитру при открытии, а не только при создании внешнего диалога.
- Стили при смене темы создаются заново без переноса истории изменений Flet; это устранило артефакты рамок, замеченные при реальном переключении.
- Ошибка чтения истории не подменяется пустым чатом. Live не добавляет несохранённые реплики при недоступной базе.

## Проверки хранения и ошибок

Временная настоящая зашифрованная БД проверяется отдельно: инструкции, материалы, принадлежность чата, черновик, повторное открытие, редактирование, удаление и откат при ошибке. Проверки интерфейса на ошибках подтверждают сохранение черновика и повтор ответа без повторной записи вопроса.

Материалы хранятся как локальные файлы. Шифрование SQLCipher защищает историю, настройки и метаданные; оно не шифрует содержимое копий материалов.

118 Python-тестов прошли с настоящим релизным нативным модулем. Четыре Rust-теста проверили выбор ключа при появлении keyring, его недоступности и повреждённой соли. Сборка Linux завершилась успешно; в пакете находится тот же нативный модуль, что проверен тестами. Пакет запущен с новым профилем и затем повторно с существующим; процесс работает и открывает базу без ошибок. Все его нативные экраны отдельно не проверялись.

## Границы подтверждения

Windows не проверен на настоящем устройстве. Установка весов из чистого профиля через интерфейс, физические устройства Windows, длинные диалоги у границы контекста модели и сохранённые файлы экспорта ещё требуют проверки. Переключения настоящего системного keyring проверены на уровне выбора ключа с тестовым поставщиком, а не перезапуском/разблокировкой ОС. Результаты тестов сами по себе не являются подтверждением полного релиза. Непрерывное видео не отправляется модели: камера и экран дают текущий кадр для каждого вопроса.
