# Xopilot Android services

Private Android Keystore database key and the official LiteRT-LM Android SDK.
Flet calls the platform service asynchronously; Python inference runs in worker
threads. No model or user data is bundled in this extension.

Both arm64-v8a and x86_64 are supported by the LiteRT-LM dependency. Actual
inference and graphics-driver support must be verified on each device.
