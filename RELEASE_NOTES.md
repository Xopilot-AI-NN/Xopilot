# dev-v2.0.13 — Rust / Dioxus

Перевёл приложение с Python/Flet на Rust, сохранил структуру проекта и привычную компоновку. Сравниваю этот пререлиз с опубликованным **dev-v2.0.12**.

- Перенёс чаты, SQLCipher, вложения, проекты, Canvas, настройки и локальные модели. Встроил LiteRT-LM, шрифты и логотип в исполняемые файлы.
- Исправил переиспользование весов и контекста модели, разбор действий агента, подтверждения и отображение шагов в переписке.
- Добавил автоматический профиль устройства, редактирование имени/аватара, тематические списки и независимую прокрутку окон.
- Исправил Android Back и возврат из фона. Сохраняю навигацию и черновик для восстановления при новом процессе; завершённые процессы и разрешения агента не запускаю повторно автоматически.
- Подключил Android DownloadManager: скачивание продолжает ОС, в системном уведомлении виден прогресс, а Xopilot после возвращения продолжает наблюдение и проверяет SHA-256.
- Учёл системные панели, вырез и экранную клавиатуру; завершённые уведомления убираю через три секунды.
- Вернул иконку, имя Xopilot и application ID by.xopilot.app. Исправил 16 КиБ ELF/ZIP-выравнивание и использую versionCode 2000013.
- Сохранил схему автосборки и публикации пререлиза, заменил Flet на Rust/Dioxus и добавил проверки упаковки.

## Файлы

| Платформа | Файлы |
|---|---|
| Linux x86_64 | `linux.zip`, `Xopilot` |
| Windows x86_64 | `windows.zip`, `Xopilot.exe` |
| Android ARM64 + x86_64 | `android.apk` |

Linux использует системные GTK3, WebKitGTK 4.1 и libxdo, Windows — Edge WebView2. Rust, Cargo, Python и инструменты сборки пользователям не нужны. Модели скачиваются отдельно из приложения.

## Переход со старого APK

Новый ключ подписи отличается от Flet-сборки. Поэтому APK с новой подписью нельзя установить поверх старого. **Не удаляйте старое приложение до экспорта нужной истории:** Keystore привязан к установке, копии зашифрованной базы недостаточно. Для следующих Rust-обновлений я сохранил один постоянный ключ в GitHub Secrets. Его публичный отпечаток находится в `App/android/signing-certificate.sha256`; закрытый ключ в репозиторий и релиз не входит.

Live, голоса, камера/экран, защищённые чаты, синхронизация и облачные устройства ещё переносятся. Реальный сервер аккаунтов и Google пока не испытывались: сервер отключён. Полный статус и результаты проверок записал в README, MIGRATION.md и tests/.
