# Проверка интерфейса — 11 ноября 2026

В настоящем Linux-окне Dioxus/WebKitGTK пройдены **56 проверок** через `scripts/check-ui.cjs`. Использовались отдельные SQLCipher, папка проекта, локальный тестовый API и тестовые профили. Личная база не открывалась.

Проверены:

- Настройки и возврат, ввод, сохранение и защита несохранённой формы; перезапуск восстанавливает черновик.
- Семь тем: собственный список с отметкой выбранной темы, размещение в пределах окна. Такой же компонент используется для документов/типа Canvas и выбора локального профиля. Меню следует за кнопкой при переходе с 1000 на 390 px, закрывается Escape.
- Карточки моделей: скачивание справа внутри карточки; импорт оригинального файла и выбор настоящей Gemma4-e2b.
- Профиль: имя редактируется по нажатию, доступен выбор аватара; основной вход предлагает Google и почту, форма регистрации содержит подтверждение пароля. Реальные запросы к серверу аккаунтов не выполнялись.
- Проекты: создание, привязка, просмотр и редактирование файла, конфликт внешней правки, удаление пространства с сохранением чата.
- Canvas и шаблоны: сохранение, переключение, отмена, подтверждаемое удаление, вставка без отправки.
- Чат: первый SSE-фрагмент отображается до завершения ответа, остановка возвращает ввод, отмена редактирования не сохраняет правку, закладки и пустой поиск, экспорт.
- Агент: ручное подтверждение конкретной записи, пауза/продолжение, отказ без изменения файла, результат после выполнения инструмента.
- Локальные профили: отдельные настройки и история, неверный пароль, повторный вход, восстановление черновиков, смена пароля и удаление одного профиля без потери гостевых данных. HTTP-запросы при этих действиях отсутствуют.
- Настоящая Gemma4-e2b ответила `4` в интерфейсе; HTTP API при генерации не использовался.

Результаты сохранены в [ui-review-results.json](ui-review-results.json). Снимки: [профиль](../previews/dioxus-profile.png), [модели](../previews/dioxus-models.png), [обновления](../previews/dioxus-updates.png), [список тем](../previews/dioxus-themed-select.png).

В ходе проверки исправлены компоновка моделей, размеры окон, дублирование стрелки собственного списка и неверные значки новых строк. Стенд ожидает первый потоковый фрагмент, а не фиксированную задержку, и выбирает пункт в открытом меню, не одноимённую кнопку под ним.

Проверка аватара включает настоящее декодирование, ограничение изображения и сохранение в SQLCipher в Rust-тесте. Системный выбор изображения на Android требует проверки телефона. Серверная авторизация/Google отложены по просьбе пользователя. Физический Android, GPU/e4b, Live, защищённые чаты и облачная синхронизация этим прогоном не проверены.
