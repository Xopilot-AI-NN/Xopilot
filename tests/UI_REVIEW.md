# Проверка интерфейса Dioxus

10 ноября 2026 года. Проверка настоящего Linux-приложения на GTK3/WebKitGTK: окна 1000×720 и 390×720, отдельная временная SQLCipher, новые тестовые чаты и файлы. Личная история не открывалась. Узкое Linux-окно не заменяет тест на Android.

## Что было сломано

| Сценарий | Результат и исправление |
|---|---|
| Открыть выдвижное меню | Панель была видна, но оставалась `inert="false"`. HTML блокирует взаимодействие при любом значении этого атрибута. Теперь атрибут удаляется; проверены клики, фокус и переход в настройки |
| Выйти из изменённого профиля/API/шаблона/проекта | Правки исчезали без вопроса. Теперь закрытие и возврат внутри настроек запрашивают подтверждение; «Остаться» сохраняет форму |
| Редактировать сообщение → Отмена → снова Изменить | Открывалась отменённая правка. Теперь редактор получает сохранённый текст |
| Поиск без совпадений | Оставалась пустая лента. Теперь показано «Ничего не найдено» |
| Переключить чат после поиска | Фильтр предыдущего чата оставался активен. При смене чата фильтры и меню сбрасываются |
| Закладки | Кнопка показывала заглушку. Теперь можно отметить сообщение, открыть закладки и искать в них; ключ `message_bookmarks_v1` совместим с Flet |
| Canvas → Новый документ в списке | Выбор пустого пункта игнорировался. Теперь создаётся пустой документ; при несохранённых правках есть подтверждение |
| Управление документами и пространствами | Добавлено удаление Canvas и пространства с подтверждением. Удаление пространства сохраняет физические файлы и чаты |
| Изменить сохранённый шаблон | Такой кнопки не было. Теперь сохраняется тот же ID без создания дубликата |
| Переключить провайдера API | Сохранялся ключ прежнего подключения. Смена адреса/пресета очищает поле ключа |
| Экспорт на узком экране | Постоянное уведомление перекрывало нижние пункты меню. Информационные уведомления исчезают через 5 секунд |

## Проверено действиями

`node scripts/check-ui.cjs` запускает отдельное настоящее окно через пример `interface_interaction`. Команды проходят через Unix socket в каталоге 0700; мост отсутствует в основном бинарнике. Нажатия проверяются через `elementFromPoint`, а не только поиском кнопки в HTML.

Итог повторного прохода: **38 проверок интерфейса**, [машинный отчёт](ui-review-results.json). Отдельно прошли 33 Rust-теста, `cargo fmt`, Clippy для headless и Desktop, сборка основного приложения `dx build --desktop -p xopilot`.

- Все шесть разделов настроек, возврат из памяти, смена темы и защита изменённой формы.
- Создание и привязка проекта; чтение, сохранение файла и конфликт с внешней правкой. Конфликт не перезаписывает файл.
- Создание, сохранение, открытие, переключение и подтверждаемое удаление Canvas.
- Создание/редактирование шаблона и добавление к уже существующему черновику без отправки.
- Настройка API через форму, настоящий HTTP/SSE к локальному тестовому серверу, отображение частичного ответа, остановка и разблокировка ввода. Ответ генерирует стенд; качество настоящей модели этим не проверяется.
- Отмена правки сообщения, закладки, поиск без совпадений, Markdown-экспорт и исчезновение уведомления.
- Новый чат из меню и сохранение черновика после завершения и повторного запуска процесса.
- Настройки, проекты, история, материалы и защищённые чаты при ширине 390 px: нет горизонтального переполнения, кнопки доступны.
- Отдельно через системный GTK chooser выбран текстовый файл; он появился в строке вложений. В автоматический стенд взаимодействие с системным chooser не входит.

## Что проверка не позволяет назвать завершённым

Внешняя похожесть ещё не означает функциональную копию Flet. В интерфейсе остались настоящие пробелы:

- Gemma4-e2b/e4b не скачиваются и не запускаются встроенным runtime.
- Диктовка, Live и выбор голосов не работают.
- Кнопка разрешений агента не открывает полноценное управление действиями.
- Защищённые чаты показывают сообщение о недоступности.
- Экран аккаунта содержит локальный профиль; облачный вход, тарифы, хранилище и синхронизация не перенесены.
- «Память обо мне» редактирует свободные инструкции, а не все категории прежней памяти.
- Проверка обновлений, рисование Canvas и офисный экспорт не перенесены.
- Материалы пока представляют собой список вложений, а не полноценную прежнюю библиотеку.

Android APK, Keystore, SAF, клавиатура, микрофон и камера на устройстве в этой проверке не испытывались. Полный перечень оставшейся работы — [MIGRATION.md](../MIGRATION.md).
