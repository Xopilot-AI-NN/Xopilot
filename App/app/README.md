# Интерфейс Xopilot

`main.py` собирает главный экран. Компоненты сгруппированы по назначению:

| Пакет | Содержимое |
|---|---|
| `theme` | Палитра, дизайн, цвета кнопок, фон (`background.py`) |
| `shared/components` | Общие кнопки подтверждения, прогресс, нативная высота чата при клавиатуре |
| `menu` | Боковое меню и его кнопки |
| `chat` | Чаты и создание новой переписки |
| `chat/messages` | Сообщения, действия над ними и музыкальный проигрыватель |
| `chat/composer` | Поле ввода и кнопки отправки, модели, микрофона, Live, вложений |
| `chat/memory` | Захват пользовательской памяти из переписки |
| `voice` | Диктовка, разговор и кнопки камеры/экрана |
| `settings` | Окно настройки API из выбора модели |
| `models` | Интерфейс скачивания моделей |
| `workspace` | Пространства, проекты, библиотека, удалённое выполнение |
| `materials` | Выбор, отображение, просмотр и экспорт вложений |
| `canvas` | Редактор и просмотр сайта |
| `browser` | Привязка ПК и удалённый браузер |
| `tasks` | Панель задач и отображение/сводки действий агента |

Основные настройки, профиль и аккаунт находятся в соседнем `App/settings`, бизнес-логика и навигация — в `App/services`. Их не нужно дублировать пустыми пакетами внутри интерфейса. Пакеты `components`, `input_prompt` и `state.py` добавляются при появлении соответствующего кода.

`__init__.py` не импортируют компоненты автоматически: это сохраняет ленивую загрузку и быстрый запуск. Поддерживаются оба способа запуска: `app.main` при запуске `App/App.py` и `App.app.main` в тестах. При перемещении модуля нужно обновить обе формы импортов, строковые пути mock/patch и шапку файла.
