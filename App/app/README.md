# Интерфейс Xopilot

`main.rs` собирает окно. Деление на папки сохранено:

| Папка | Ответственность |
|---|---|
| `theme` | Палитра и общие стили |
| `menu` | Навигация и история чатов |
| `chat` | История и поиск сообщений |
| `chat/messages` | Сообщения, Markdown, редактирование и удаление |
| `chat/composer` | Строка ввода и шаблоны |
| `chat/composer/buttons` | Отправка, отмена и файловый диалог |
| `settings` | Настройка модели/API |
| `workspace` | Проекты, поиск и редактор файлов |
| `canvas` | Документы и изолированный HTML-предпросмотр |

`state.rs` хранит состояние и обработчики окна. Общие настройки находятся в соседнем `App/settings`, бизнес-логика — в `App/services`. Неперенесённые разделы не заменяются пустыми компонентами; их список находится в [MIGRATION.md](../../MIGRATION.md).

Функции компонентов называются `build_*`, как раньше. В RSX их вызываем через путь модуля (`chat::build_chat {}`), чтобы Dioxus отличал имя компонента от HTML-тега.
