# Идентификатор Android-приложения

Основной пакет — `by.xopilot.app`. Он задан в `Dioxus.toml`, сборка выполняется через `scripts/build_android.sh`.

Для обновления существующей установки нужны прежний application ID, исходный ключ подписи и увеличенный versionCode. Debug APK с другим ключом не заменяет прежнюю установку. Не удаляйте её ради установки тестовой сборки: это может уничтожить ключ Keystore и локальную историю.

Шаблон Dioxus пока формирует versionCode=1. Перед выпуском обновления его нужно увеличить. Keystore использует прежние preferences `xopilot_keys` и alias `xopilot.database.v1`; перенос на физическом устройстве ещё не проверен. Копирование папки через ADB не переносит аппаратный ключ.

Синхронизация и автоматический перенос между разными application ID в текущей Rust-версии не реализованы.
