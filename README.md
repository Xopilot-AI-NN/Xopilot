Результаты проверок — [Rust / Linux](tests/RUST_DIOXUS.md) и [Android](tests/ANDROID_DEVICE.md). Локальная сборка не означает, что новый релиз уже опубликован.

## Возможности

| Для чего | Что умеет Xopilot |
|---|---|
| **Общение** | История и поиск чатов и сообщений, локальные закладки, редактирование, экспорт Markdown, шаблоны запросов, вложения, потоковый ответ и отмена, выбор локальной модели или API |
| **Проекты** | Рабочие пространства с инструкциями и выбранной папкой; поиск по коду, чтение и изменение файлов, Git status/diff, выполнение команд в подключённом проекте |
| **Canvas** | Текст и Markdown, код, изолированный предпросмотр HTML, сохранение и переключение документов; рисунки прежней версии сохраняются, редактор рисования ещё переносится |
| **Память** | Личные инструкции и сохранённые сведения, редактирование в персонализации и подтверждаемое сохранение агентом |
| **Агент** | Файлы проекта, Canvas, поиск чатов и память; шаги с раскрываемыми результатами в переписке, пауза и остановка, подтверждения или явно выбранный автоматический режим |
| **Локальные модели** | Gemma4-e2b/e4b через встроенный LiteRT-LM: скачивание с паузой, проверка SHA-256, импорт `.litertlm` одной кнопкой, автоматический выбор GPU/CPU и освобождение памяти |
| **Аккаунт** | Автоматический профиль устройства без регистрации, имя и аватар по нажатию; формы Google, входа по почте и регистрации для прежнего сервера |
| **Live** | Голосовой интерфейс предусмотрен; диктовка, голоса, камера и экран ещё переносятся |
| **Между устройствами** | Синхронизация, связанные компьютеры и удалённые задания прежней версии ещё не подключены к Rust-интерфейсу |
| **Хранилище и приватность** | История и настройки в SQLCipher, локальные вложения и экспорт; облачные материалы и защищённые чаты с отдельным паролем ещё переносятся |

Локальные модели и свой API-ключ можно использовать без покупки облачной модели Xopilot. Встроенная модель запускается без внешнего сервера. Подключение Ollama или llama-server через API также возможно, но эти серверы запускаются отдельно. Поддержка изображений и аудио зависит от выбранной модели.

Веса локальной модели остаются в памяти между запросами. При продолжении разговора дополняется готовый контекст; редактирование истории или инструкций пересоздаёт контекст без повторной загрузки весов. Нативное окно сейчас ограничено 4096 токенами; общая автоматическая сводка длинной переписки ещё не перенесена. Расширенная история инструментов сокращается перед заполнением окна. Исходные сообщения в базе сохраняются.

Агент проверяет формат ответа и результаты инструментов. Типичные заявления о выполнении без успешного действия отправляются модели на исправление; это не гарантия безошибочного понимания любого запроса. Явно процитированный текст при создании Canvas проверяется до записи. Приложение ограничивает доступ выбранной папкой проекта и проверяет подтверждения независимо от ответа модели.

В подключённом проекте доступны поиск по коду, Git и редактор с проверкой внешних изменений. Файл, изменённый после открытия или чтения агентом, не перезаписывается по устаревшей версии. Команды выполняются с правами пользователя в выбранной папке, ограничены временем и объёмом вывода; это не отдельная ОС-песочница.

Интерфейс использует общие палитры, карточки, списки и индикаторы. Разделы окон сохраняют собственную прокрутку. Уведомления появляются над вводом в чате и сверху справа вне чата, исчезают через 3 секунды; активные загрузки и подтверждения остаются видимыми. Лёгкие анимации учитывают `prefers-reduced-motion`.

## Платформы

- **Linux** — основной настольный интерфейс, локальный ИИ и инструменты проектов. Gemma4-e2b проверена на CPU; e4b и GPU отдельно не испытывались.
- **Android** — Dioxus Mobile и системный WebView, Android Keystore и адаптивный интерфейс. Rust 2.0.13 проверяется на POCO X5 5G отдельной установкой. Учтены системные панели, вырез экрана и экранная клавиатура. Подробности — [ANDROID_DEVICE.md](tests/ANDROID_DEVICE.md).
- **Windows** — предусмотрены платформенные пути и ссылки; отдельная актуальная сборка не проверена.
- **ChromeOS** — отдельное устройство пока не проверено.

Автоматический выбор вычислений использует оценку свободной памяти: GPU выбирается при достаточном запасе, иначе CPU. Если GPU не удалось инициализировать до первого текста, допускается откат на CPU. История хранится в SQLCipher на устройстве; размещением тензоров и KV-кеша управляет LiteRT-LM. Тяжёлая модель подходит не каждому телефону.

## Синхронизация и защита данных

Профиль автоматически создаётся при первом запуске; локальная регистрация не требуется. Сохраняются UUID, имя, аватар и история. Прежние файлы локальных аккаунтов не удаляются.

История, настройки и API-ключи находятся в SQLCipher. Локальные материалы и экспортированные Markdown-файлы хранятся отдельно от зашифрованной базы. Внешний API получает историю выбранного чата и прикреплённые материалы, а не всю базу. Локальная модель не отправляет переписку в сеть.

Вход через Google, почту и регистрация используют прежний `/api/v1`. Реальная проверка отложена до включения сервера. Облачная синхронизация пока не выполняется; прежние настройки и неизвестные поля сохраняются при работе с профилем.

На Linux используется `$XDG_DATA_HOME/Xopilot` (обычно `~/.local/share/Xopilot`), на Android — приватный каталог приложения и Keystore. При недоступном ключе программа показывает ошибку и не создаёт новую историю поверх прежней.

## Подписки Zephyr

Облачные тарифы, биллинг и удалённые задания относятся к прежней серверной части и ещё не подключены к Rust-версии. Сервер отключён, оплата не активирована. Локальная модель и свой API не требуют подписки.

## Быстрый старт

Для разработки используются **Rust stable**, Dioxus CLI **0.7.10** и системные библиотеки целевой платформы. Python, Flet и Flutter не нужны. Структура приложения сохранена, Rust-модули сопровождаются русскими комментариями.

```bash
# Arch Linux
sudo pacman -S --needed base-devel pkgconf perl gtk3 webkit2gtk-4.1 xdotool curl unzip zip

# Debian / Ubuntu
sudo apt-get install build-essential pkg-config perl libgtk-3-dev libwebkit2gtk-4.1-dev libxdo-dev curl unzip zip

cargo install dioxus-cli --version 0.7.10 --locked
./scripts/prepare_runtime.sh
dx serve --desktop -p xopilot

# Сборка Linux с ресурсами
./scripts/build_linux.sh
# Результат: target/dx/xopilot/release/linux/app/
```

При `dx serve` процесс может называться `xopilot-<случайный ID>`: Dioxus создаёт копию для очередного запуска. Обычный собранный файл называется `xopilot`, название приложения — Xopilot.

`prepare_runtime.sh` загружает закреплённый официальный [LiteRT-LM C API 1.0.0](https://github.com/google-ai-edge/LiteRT-LM/releases/tag/v0.19.1), проверяет SHA-256 и подготавливает лицензии. Без SDK работает API, но не встроенная модель. В установленное приложение runtime включается при сборке; Rust, Cargo и Dioxus CLI нужны только разработчику. Для Linux-пакета также нужны системные WebKitGTK/GTK3/libxdo.

```bash
# Android arm64: JDK 21, SDK 35, Build Tools 34/35, NDK 27.2.12479018
rustup target add aarch64-linux-android
export JAVA_HOME=/path/to/jdk-21
export ANDROID_HOME=/path/to/Android/Sdk
export ANDROID_NDK_HOME="$ANDROID_HOME/ndk/27.2.12479018"
./scripts/build_android.sh
./scripts/test.sh apk
```

Android-пользователь устанавливает APK, приложение использует системный WebView. Для обновления прежней установки нужны прежний ключ подписи и увеличенный versionCode. Тестовый пакет `by.xopilot.preview` устанавливается отдельно и не меняет данные `by.xopilot.app`.

```bash
# Проверки сервисов
./scripts/test.sh quick
# Форматирование, тесты и Clippy
./scripts/test.sh full
# Настоящий Linux-интерфейс; нужен Node.js и графический сеанс
./scripts/test.sh ui
# Настоящая локальная модель; оригинальный файл уже должен быть скачан
./scripts/test.sh model /путь/gemma-4-E2B-it.litertlm
```

Сборочные сценарии находятся в [scripts](scripts), CI — в [.github/workflows/build.yml](.github/workflows/build.yml). Отчёты: [Rust / Dioxus](tests/RUST_DIOXUS.md), [Linux UI](tests/UI_REVIEW.md), [Android](tests/ANDROID_DEVICE.md). Полный статус переноса — [MIGRATION.md](MIGRATION.md).

## Устройство проекта

```text
Cargo.toml      Rust workspace
App/
  main.rs       запуск Linux / Android
  app/          интерфейс: чат, проекты, Canvas, общие компоненты
  services/     модели, агент, профили, платформенные функции
  settings/     настройки и аккаунт
  assets/       графика, шрифты и ресурсы
  native/       нативный runtime и лицензии, подготовка при сборке
Services/       библиотека Rust / SQLCipher
scripts/        сборка и проверка артефактов
tests/          тесты и отчёты проверок
```

Серверная часть и админ-панель развёртываются отдельно; их исходников и секретов в этом репозитории нет. Не добавляйте в issues ключи API, токены, личные переписки или файлы OAuth.
